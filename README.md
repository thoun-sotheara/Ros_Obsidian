# RoS Obsidian

A workspace containing the Rules of Survival emulator and iOS inspection/deployment materials.

## Contents

- `Ros-Emulator/` — server emulator source.
- `IPA_IOS/` — iOS package scripts and non-packaged source/materials. Packaged binaries and app payload assets are intentionally excluded.

## Safety

This repository excludes virtual environments, private keys, credentials, SQLite databases, logs, packaged IPA/ZIP archives, game binaries, and large app payload assets. Review every exported file before running or distributing it.
